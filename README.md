# Task management
A Kanban-style task manager written in Python using PyQt6.

## Possibilities
1. **Columns**: New, In work, Block, Need recheck, Done
2. Colors for task prioritization
3. **Editing**: double-click a card to edit the text
4. **Background images**: a unique background for every space
5. **Multiple spaces**: separate boards
6. **Drag-and-Drop**: dragging and dropping cards between columns
7. **Scrolling with the mouse wheel**: while dragging
8. **Creation date**: automatically added to every task
9. **Autosave**: all changes are saved to local files

## Installation
- Python 3.10 +
- PyQt6
